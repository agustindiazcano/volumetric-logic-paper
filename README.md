## Overview

This repository contains the first public draft of the paper:

**Volumetric Logic (VL): A Volumetric Decision Algebra for Deterministic Decision Functions**

Volumetric Logic (VL) is a geometry-first decision formalism for deterministic signals in $\mathbb{R}^n$, based on finite collections of weighted closed balls and a normalized radial proximity operator. The framework induces continuous conic membership semantics through max-aggregation of simple distance-to-radius terms, yielding interpretable decision maps with $\mathcal{O}(kn)$ evaluation cost for $k$ components in $n$ dimensions.

The paper develops the formal definition of VL, its semantic algebra, its relation to fuzzy inference systems and prototype-based models, and a constructive approximation result for Lipschitz functions on compact domains.

## Main contributions

- Formal definition of volumetric signals and volumetric predicates
- Semantic lattice structure under pointwise logical operations
- Embedding into zero-order max-aggregation fuzzy inference systems
- Constructive approximation result for Lipschitz functions
- Efficient evaluation with $\mathcal{O}(kn)$ complexity
